# GEMINI.md

Read and follow `AGENTS.md` — it is the canon for all agents (Gemini CLI,
Codex, Cursor, Windsurf, Aider and any agent that reads a file).
Selected philosophies are listed in `.controlroom/config.json`.

Skills are plain files in `.claude/skills/<name>/SKILL.md`; the reviewer
role is `.claude/agents/code-reviewer.md`. When your task is planning,
building (`ponytail`), TDD, debugging or review, open the matching file
and follow it before starting. Review runs in a separate agent instance.
