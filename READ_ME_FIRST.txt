CONTROLROOM

1. Open installer/index.html for the clickable pre-install selector.
2. Choose All philosophies or select individual philosophies.
3. Download controlroom.config.json.
4. Review the file before installation.
5. Run:
   python scripts/controlroom.py install PATH_TO_REPOSITORY --config PATH_TO_CONFIG

Core safety and integrity rules are always installed. No target repository is changed before step 5.
