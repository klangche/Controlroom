# Status

Work is tracked in GitHub issues and pull requests.

- A plan issue defines the goal.
- Ordered sub-issues define the steps and checks.
- One issue maps to one branch and one pull request.
- `status/` may contain temporary human-readable handover notes, but GitHub remains the source of truth.
- A task is complete only after checks pass, independent review is recorded, required CI is green, and the pull request closes the issue.
