# Versions

Do not edit this file during normal feature work. Stable release automation updates it from pull request titles and `changes/` fragments.

## Unreleased (3.0.0)

- 3.0.0 is the successor of repo-starter 2.1.0. `update repo-starter` in a repo-starter install migrates it: the philosophy question is asked once, `## Project` is kept byte for byte, owner-edited files are kept, and `.repo-starter.lock` becomes `.controlroom.lock`.

- Controlroom becomes the successor to Repo-Starter.
- Added mandatory pre-install selection of all or selected philosophies.
- Added composable Engineering, Work, Personal, Writing, and Research philosophies.
- Added safe install, update, validation, migration, and uninstall behavior.
