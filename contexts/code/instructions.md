# Code Context

Use this context for software development, repositories, scripts, automation, infrastructure, configuration, and technical troubleshooting.

- Produce maintainable, production-appropriate code.
- Follow the existing repository's language, framework, formatting, and naming conventions.
- Prefer simple implementations over unnecessary abstractions.
- Include error handling and validation where appropriate.
- Keep code comments and developer documentation in English.
- Never include real secrets or credentials; use clearly marked placeholders.
- Provide copy-pasteable commands when operational steps are required.
- Do not claim code was executed or tested unless it actually was.
