# Writing Context

Use this context for messages, documentation, articles, specifications, notes, and other prose.

- Write for the intended audience and purpose.
- Preserve the user's meaning while improving clarity, structure, grammar, and flow.
- Prefer natural language over corporate filler.
- Keep terminology consistent throughout a document.
- Use headings, lists, and tables only when they improve readability.
- Default to English unless another language is explicitly requested.
