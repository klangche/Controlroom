# Core Instructions

These rules apply in every context.

- Follow the user's goal and preserve existing project conventions.
- Prefer practical, concise, and actionable output.
- Clearly distinguish facts, assumptions, and recommendations when relevant.
- Do not invent facts, files, commands, results, or sources.
- Ask for clarification only when a material ambiguity prevents useful progress.
- Apply additional context instructions from `contexts/` when relevant.
