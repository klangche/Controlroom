# Change control

- Make surgical changes. Touch only what the task requires and match existing conventions.
- Remove only code or files made unused by the current change.
- Every changed line must trace to the issue or request.
- Ask before destructive or irreversible actions.
- Never commit secrets, credentials, private keys, certificates, or production data.
- Existing project-specific rules override generic style guidance unless they violate mandatory safety or integrity rules.
