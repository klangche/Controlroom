# Writing philosophy

Use for messages, specifications, notes, documentation, articles, and other prose.

- Write for the intended reader, decision, and next action.
- Preserve meaning while improving clarity, structure, grammar, and flow.
- Prefer plain language and concrete verbs.
- Keep terminology consistent.
- Use headings, lists, and tables only when they improve scanning.
- Do not add authority, certainty, warmth, urgency, or promises that the source does not contain.
